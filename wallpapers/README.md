# Wallpapers

Coloca aqui wallpapers nuevos o livianos que quieras versionar manualmente.

Las imagenes personales pesadas de `~/Pictures` no se copiaron al repositorio. La configuracion actual de Hyprpaper referencia:

- `/home/jfranco/Pictures/wallpaper.jpg`

En una maquina nueva puedes crear ese archivo, cambiar `hypr/.config/hypr/hyprpaper.conf`, o usar `~/Pictures/wallpaper/` como carpeta preparada.
